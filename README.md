#  TransitOps - Smart Transport Operations Platform

# Project Overview

TransitOps is a web-based Smart Transport Operations Platform developed for the Odoo Hackathon. The platform helps transport organizations efficiently manage buses, drivers, routes, passengers, and real-time vehicle tracking through a centralized dashboard.


# Problem Statement

Develop a smart transport management platform that improves operational efficiency by digitizing fleet management, route planning, driver allocation, passenger information, and analytics.

# Installation

Clone the repository

```bash
git clone https://github.com/your-username/transitops.git
```

Go to the project folder

```bash
cd transitops
```

Install dependencies

```bash
npm install
```

Run the server

```bash
npm start
```
